# PingKit Agent

Watches your own network from Home Assistant and tells PingKit on your iPhone when the
internet goes down (about three minutes) and comes back, when a new device joins, and, if
you turn it on, when a device goes offline (up to 45 minutes at the default sweep).

Pair it with the code your iPhone shows under Agents > Add an Agent. Running the agent is
free; iPhone alerts need PingKit Guardian. See the Documentation tab.

This is a Home Assistant app, which Home Assistant called an add-on before 2026.2.
